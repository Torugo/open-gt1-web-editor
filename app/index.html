    One-time setup
    
    
    This editor doesn't include any Roland files. It reads the GT-1 parameter list and factory presets from
      your own copy of BOSS TONE STUDIO for GT-1. The files stay on this computer: nothing is uploaded.
    
    
    Use any one of these:
    
    
      
      
    • The Windows download from BOSS, e.g. bts_gt1_w102.zip, or the installer .exe inside it.
        It works on any computer (Mac and Linux too), since only its data is read.
        Get it from boss.info → GT-1 → Support → Updates & Drivers.
      • 
      
    • The installed program folder: on Windows usually C:\Program Files (x86)\BOSS TONE STUDIO for GT-1;
        on a Mac, drop BOSS TONE STUDIO for GT-1.app from Applications here.
      •
